## Overview

A quick reference for key terms used throughout Graphium AI.

---

**Admin** -- The highest vault permission role. Full access to manage the vault, its users, and all data. Can configure tables, schemas, connections, playbooks, assistants, and permissions.

**Artifact** -- A finished page, such as a one-pager or report, that an AI assistant creates in a conversation. Artifacts open in their own viewer and keep a version history.

**Assistant (AI Assistant)** -- A configurable AI agent scoped to a specific vault's data. Assistants are configured with a system prompt, table access controls, and connection actions. Users interact with them through natural language chat. Also referred to as agents.

**Auto ID** -- A field type that automatically generates a unique identifier for each record (e.g., AAC-01001, REQ-0200).

**Builder** -- A vault permission role. Can create and modify tables, schemas, assistants, and playbooks, but cannot manage users or vault-level settings. Also a workspace seat type, and the Builder view of the vault sidebar.

**Chat Context** -- The panel (⚙ in the chat input bar) that sets which tables, tools, connections, and AI model the assistant can use in a conversation.

**Collection** -- A property that holds a list of values instead of a single value, created by turning on **Allow multiple values**. Shown in the schema as the type plus "Collection" — for example, a Procedure Codes field of type **Text Collection** that holds several CPT codes for one case.

**Connection** -- A bidirectional data pipeline between a Graphium AI vault and an external system (EMR, spreadsheet, database, CRM, etc.). Connections sync data in and out and expose actions that assistants and playbooks can use.

**Connection Action** -- A specific event or operation exposed by a connection type. Examples: "Case Created" (Graphium EMR), "Row Added" (Google Sheets), "Survey Completed" (Graphium Surveys). Actions can trigger playbooks or be made available to AI assistants.

**Contributor** -- A vault permission role. Can add and edit data within tables but cannot modify the vault's structure (schemas, playbooks, connections). Also a workspace seat type, and the streamlined Contributor view of the vault sidebar.

**Data Tab** -- The default tab of a table, showing its records in a grid with columns, pagination, and a Load More option.

**Field** -- A single property within a table schema. Each field has a name, a key (snake_case identifier), and a type (Text, Number, Date, etc.).

**Formula** -- A property type whose value is calculated from other properties in the same record.

**General Assistant** -- The assistant built into every vault. It has no specialized focus and answers questions using whatever is enabled in Chat Context.

**Image** -- A field type for storing image data. Used for attaching photographs, documents, or visual records to a record.

**Managed Table** -- A table whose schema is owned by an external connection (e.g., "Managed by Graphium EMR"). The schema is read-only and cannot be modified within Graphium AI; changes must be made in the source system.

**Member** -- A workspace-level role. Members have standard access to the workspace and can be added to individual vaults with vault-level roles (Admin, Builder, Contributor, or Viewer). Members cannot manage workspace settings, billing, or workspace membership.

**Object** -- A property type that acts as a container for child properties, so related fields can be grouped and nested. Example: a "Patient Demographics" object containing Date of Birth, Gender, and Insurance.

**Organization** -- See Workspace.

**Owner** -- The highest workspace-level role. Owners have full access to manage the workspace, including inviting and deactivating members, managing billing and subscriptions, and configuring workspace settings. Only Owners can view the Members page and access the Billing section.

**Playbook** -- An automated AI workflow that runs inside a vault. Playbooks are configured with plain-language steps, a trigger (manual or scheduled), and access to vault tables, connections, and tools. Each run is tracked in the Run History panel. See also: [What are Playbooks?](/graphium/core-concepts/playbooks)

**Record** -- A single data entry within a table. Records have field values that conform to the table's schema and may include a status lifecycle (e.g., Submitted, In Review, Ready to Bill, Paid).

**Reference** -- A field type that links to a record in another table, functioning as a foreign key. Example: a "Provider" field in the Cases table that references the Providers table.

**Schema** -- The structure definition of a table, consisting of an ordered list of fields with their names, keys, and types. Schemas can be hierarchical (using Objects) and may include cross-table relationships (using References).

**Schema Tab** -- The table tab that lists the table's properties (fields) for editing, showing each one's name, key, type, and nesting.

**Seat Type** -- How a workspace member is billed: a **Builder** seat or a **Contributor** seat. Set on the Members tab of Workspace Settings.

**Select from List** -- A property type whose value is picked from a predefined list of options.

**Signature** -- A field type for capturing digital signatures. Used for provider sign-offs and document authentication.

**System Prompt** -- The configuration text that defines an AI assistant's role, personality, domain expertise, and behavioral guidelines. Set in the General tab of assistant configuration.

**Table** -- A structured data collection within a vault, defined by a schema of hierarchical properties. Vaults can contain multiple tables (e.g., Cases, Procedures, Providers).

**Trigger** -- The event or schedule that initiates a playbook. Types include manual triggers, time-based schedules, and connection events.

**Vault** -- The central organizing unit in Graphium AI. A secure workspace that contains tables, connections, AI assistants, and playbooks. Each vault is scoped to a specific dataset or use case.

**Viewer** -- The lowest vault permission role. Read-only access to view data. Cannot add, edit, or configure anything. Suitable for auditors, external reviewers, or stakeholders.

**Workspace** -- The top-level grouping in Graphium AI. Users can belong to multiple workspaces and switch between them. Each workspace has its own vaults, assistants, and settings. Also called an Organization.
