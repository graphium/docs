## Overview

When you sign in to Graphium AI, the workspace home opens on the **Assistants** tab. It lists the custom assistants you can use across every vault in the workspace, so you can start a chat with the right assistant without opening its vault first. Your vaults are one click away on the **Vaults** tab.

## When to Use This

- Starting a chat with a specialized assistant — for example, a claims or credentialing tracker — straight from the workspace home
- Seeing which assistants your team has set up, and which vault each one works in
- Creating a new assistant by describing what you need help with
- Opening an assistant's settings (vault Admins)

## Prerequisites

- You are signed in and a member of the workspace
- To see an assistant here, you must have access to its vault and to the assistant itself. An assistant's **Who Can Access** setting controls which vault roles can use it.

## Step-by-Step Instructions

### Step 1: Open the workspace home

Sign in, or click the **Graphium** logo in the top-left corner. The workspace home opens with two tabs:

- **Assistants** (the default) — the assistants you can use in this workspace
- **Vaults** — your vaults. See [Viewing and Opening Vaults](/graphium/vaults/viewing-and-opening-vaults).

The line under **Your Assistants** shows how many assistants you have and how many vaults they're spread across — for example, *3 assistants across 3 vaults*.

> **Note:** The **General Assistant** isn't listed here. Every vault has one — open a vault to chat with it.

### Step 2: Find the assistant you want

Each assistant card shows:

- The assistant's icon, name, and description
- The **vault** it works in
- How many **tables** and **connections** it can use
- A **Chat** link, and a ⚙ **Configure** button for vault Admins

Use the toggle in the top-right corner to switch between the card grid and a list view. The list view shows the same details in columns (Assistant, Vault, Tables, Connections, Actions), with **Chat** and ⚙ buttons on each row. Graphium AI remembers the view you chose.

  <img src="/images/graphium/assistant/workspace-assistants-list.png" alt="Assistants tab in list view, with Assistant, Vault, Tables, Connections, and Actions columns and an Add an assistant button" />

### Step 3: Start a chat

Click the assistant's card, or click **Chat**. The assistant's vault opens on the **Home** page with a new chat for that assistant — the assistant's name appears above the heading, and the chat input reads *"Ask [assistant name]…"*.

From here, chatting works the same as always. See [Chatting with Your AI Assistant](/graphium/ai-assistants/chatting-with-your-ai-assistant).

### Step 4: Add an assistant (optional)

Click the **Add an assistant** tile (*"Say what you need help with, and we'll set one up for you"*) — or **+ Add an assistant** in list view — to create one by describing it. See [Creating an AI Assistant](/graphium/ai-assistants/creating-an-ai-assistant).

If you don't have any assistants yet, the Assistants tab shows a **Create your first assistant** panel in place of the card list.

### Step 5: Open an assistant's settings (Admins only)

Click the ⚙ button on an assistant's card or row. The assistant's settings page opens in its vault. See [Managing Your AI Assistants](/graphium/ai-assistants/managing-your-ai-assistants).

## What to Expect

- The Assistants tab only lists published, active assistants. Archived assistants don't appear.
- Opening an assistant from here always starts a new chat. To pick up an earlier conversation, open it from the vault's **CHATS** list or **Recent Chats** — see [The AI Assistant Home Page](/graphium/ai-assistants/the-ai-assistant-welcome-screen).
- Inside a vault, the back arrow (←) in the vault header returns you to the workspace home.

## Common Issues & Troubleshooting

| Issue | Likely Cause | Solution |
|-------|-------------|----------|
| The General Assistant isn't listed | The General Assistant is part of every vault, so it isn't listed separately | Open a vault from the **Vaults** tab and chat from the vault's Home page |
| An assistant I expected isn't listed | It's archived, not yet published, restricted to other vault roles, or in a vault you can't access | Ask a vault Admin to check the assistant's status and **Who Can Access** setting, or to add you to the vault |
| The ⚙ button is missing | You aren't an Admin of that assistant's vault | Builders can open the assistant's settings inside the vault from **Manage assistants** in the assistant selector. Otherwise, ask a vault Admin |
| The **Add an assistant** tile is missing | You can't create assistants in any vault and can't create vaults, or the workspace has reached its assistant limit | See [Creating an AI Assistant](/graphium/ai-assistants/creating-an-ai-assistant) |
| The Assistants tab shows only a **Create your first assistant** panel | You don't have any assistants yet | Describe what you need help with to create one, or open a vault and use its General Assistant |
| I want to see my vaults | The workspace home opens on the Assistants tab | Click the **Vaults** tab |
