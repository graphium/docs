## Overview

An **artifact** is a finished, formatted page that the AI Assistant builds for you from a conversation — for example, a quarterly results one-pager, a patient guide, or a summary of records from your vault tables. Artifacts appear as a card in the assistant's reply and open in a viewer beside the chat, where you can expand them, open them in a new tab, and switch between versions as you ask for changes.

> **Note:** Artifacts are different from charts. A chart is a quick visualization shown inside the reply itself (see [Configuring Chat Context and Query Tools](/graphium/ai-assistants/configuring-chat-context-and-query-tools)). An artifact is a complete page that opens in its own viewer and keeps a version history.

## When to Use This

- Turning notes or figures you paste into the chat into a polished page, such as a one-pager, handout, or report
- Building a summary page from data in one or more of your vault tables
- Revising a page over several rounds ("add a section," "use a warmer look") while keeping earlier versions available

## Prerequisites

- You must have access to the vault and be able to use the AI Assistant on the vault Home page
- To build an artifact from vault data, the tables it needs must be enabled for the assistant in **Chat Context** — see [Configuring Chat Context and Query Tools](/graphium/ai-assistants/configuring-chat-context-and-query-tools)

There is no setting to turn on. The assistant creates an artifact whenever your request calls for a finished page.

## Step-by-Step Instructions

### Step 1: Ask the Assistant for a Page

On the vault Home page, describe the page you want in the chat input bar and send it. The assistant does its best work when you give it real content to work from — paste your notes or figures, then say what to build.

*Example:* "Here are our Q3 results: Revenue $4.2M, up 18% from Q2. Gross margin 63%. New customers 214. Churn 2.1%. Cash runway 19 months. Turn this into a quarterly results one-pager."

The assistant's reply includes an **artifact card** showing the page title and **Version 1**, followed by a short description of what it built.

> 💡 **Tip:** The assistant chooses a color theme that suits the subject — for example, a calm blue look for medical content or a deep slate look for financial reports. If you want a particular look, say so in your request (for example, "use a warm, earthy look").

### Step 2: Open the Artifact

Click the artifact card. The artifact opens in a panel beside the chat, and you can keep chatting while it's open — for example, to ask a question about the page.

The panel header shows the artifact's title and version, plus three buttons:

| Button | What it does |
|---|---|
| **Expand** | Fills the content area with the artifact and hides the chat. Click it again to show the conversation alongside the artifact |
| **Open in new tab** | Opens the artifact on its own in a new browser tab |
| **Close** | Closes the viewer |

<Frame>
  <img src="/images/graphium/assistant/artifact-split-panel.png" alt="Artifact open in a panel beside the chat, with Expand, Open in new tab, and Close buttons in the panel header" />
</Frame>

Every artifact ends with a **Generated with Graphium** footer. Artifacts are self-contained pages: they don't load outside content, and links or buttons on the page won't take you away from Graphium AI.

> 💡 **Tip:** You can press **Esc** to close the viewer. If you've clicked inside the artifact, use the **Close** button instead.

### Step 3: Ask for Changes

To revise an artifact, send a follow-up that refers to it — for example, "Update the previous artifact to add a Next Quarter Priorities section and keep everything else the same." Wording such as "change that to…," "modify the artifact so…," or "redo it with…" also works.

The assistant saves your change as a **new version** of the same artifact. A new card appears in the reply showing the next version number (for example, **Version 2**). Earlier versions are kept — nothing is overwritten.

> 💡 **Tip:** Be clear that you want to change the existing artifact. A vague request may produce a separate, new artifact instead.

### Step 4: Switch Between Versions

When an artifact has more than one version, the version label in the viewer header becomes a drop-down.

1. Open the artifact.
2. Click the version drop-down (for example, **Version 3**) and select the version you want to see.

Opening the newest card always shows the latest version. Older cards earlier in the conversation still open the version they were created with.

## Building an Artifact from Vault Data

You can ask the assistant to build an artifact from records in your vault tables — for example, "Create an artifact that combines data from my Providers and Invoices tables into one summary page, with a section for each."

- The assistant reads only the tables it has been given access to in **Chat Context**.
- The artifact captures the data **as it was when the artifact was created**. Later changes to the table don't update it — ask the assistant to create a new version to refresh the data.
- If you later remove the assistant's access to a table, artifacts that were already built from it keep their data.

If your request needs a table the assistant can't access, it won't build a partial artifact. Instead, the reply shows an **Access required** card naming the table, with a **Review table access** button. Click it to open the Chat Context panel, give the assistant access to the table, and then ask again.

## What to Expect

- Artifacts stay with the conversation. Reopen the conversation later and the artifact cards are still there.
- A link to an artifact opened in a new tab still requires signing in, and only people with access to the vault can view it.
- Artifact content is generated by AI, so wording and layout can differ each time. Review the page — especially any figures — before sharing it.

## Common Issues & Troubleshooting

| Issue | Likely Cause | Solution |
|-------|-------------|----------|
| The assistant answered in the chat instead of creating an artifact | The request didn't clearly ask for a page | Ask for a specific kind of page, such as "turn this into a one-pager" or "create an artifact that…" |
| A change created a new, separate artifact instead of a new version | The follow-up didn't clearly refer to the existing artifact | Say "update the previous artifact…" or "change that artifact to…" |
| The open viewer still shows an older version after a change | The viewer doesn't always refresh when a new version arrives | Close the viewer and click the newest artifact card |
| **Esc** doesn't close the viewer | You clicked inside the artifact, so the keyboard is focused on the page | Click **Close** in the panel header |
| The assistant says it can't find or access a table | The table isn't enabled for the assistant in Chat Context | Click **Review table access** if a card appears, or open Chat Context and set the table to **Read**, then ask again |
| The artifact doesn't show recent changes to a table | Artifacts capture data at the moment they're created | Ask the assistant to update the artifact so it creates a new version with current data |
| A shared artifact link opens the sign-in page | Artifact links require signing in and access to the vault | Sign in with an account that has access to the vault |
