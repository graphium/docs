## Overview

The Custom Assistants page of your vault is where Admins and Builders configure, edit, and archive the AI assistants available to your team. Each assistant is a distinct agent with its own name, icon, description, AI model, system prompt, tools, and access settings.

Assistants use a **Save → Publish** versioning workflow. Clicking **Save** creates a new draft version of the assistant — drafts are not visible to vault members until you click **Publish** to make a version the active live version. (An assistant created with **+ New Assistant** is published as Version 1 right away; any edits you make after that follow the same Save → Publish workflow.)

This article covers how to view, edit, publish, duplicate, and archive your assistants. To create one, see [Creating an AI Assistant](/graphium/ai-assistants/creating-an-ai-assistant).

---

## Viewing Your Assistants

From within a vault, open the Custom Assistants page:

- **Admins** — click the **⚙ (Manage assistants)** button next to the **ASSISTANTS** heading in the left sidebar.
- **Admins and Builders** — click the assistant selector above the chat, then click **Manage assistants** at the bottom.

The **Custom Assistants** page opens, showing how many assistants are active and archived and a card for each one.

To see assistants across all your vaults, use the **Assistants** tab of the workspace home — see [The AI Assistant Home Page](/graphium/ai-assistants/the-ai-assistant-welcome-screen#starting-from-the-workspace-home). Vault Admins can click an assistant's ⚙ there to open its settings.

Each assistant card displays:

- **Icon and color** — The visual identifier for the assistant
- **Name** — The assistant's display name
- **Description** — A brief summary of what the assistant does
- **Resource counts** — How many tables and connections the assistant has access to

Use the **grid/list toggle** in the top-right corner to switch between card grid and list view.

If no assistants have been created yet, the page shows an empty state: *"No assistants yet — Create specialized AI assistants with custom prompts and data access to help with specific tasks."*

## Creating a New Assistant

Only **Admin** and **Builder** vault members can create assistants. On the Custom Assistants page, click **+ New Assistant** to describe the assistant and have Graphium AI set it up, or **Advanced setup** to configure every setting yourself. For both, see [Creating an AI Assistant](/graphium/ai-assistants/creating-an-ai-assistant).

## Editing an Assistant

To edit an existing assistant, open the Assistants list and click any assistant card. The same editor opens with the assistant's current configuration loaded.

Make your changes across either tab — for what each setting does, see [Using Advanced Setup](/graphium/ai-assistants/creating-an-ai-assistant#using-advanced-setup) — then click **Save** to save them as a new draft version. Click **Publish** to make the updated version live for all vault members. Until you publish, users continue seeing the previously published version.

> 💡 **Tip:** Use the Test Chat panel to verify your changes before publishing — especially when updating the system prompt.

## Duplicating an Assistant

To create a copy of an existing assistant — useful for creating a variant with a different system prompt or tool configuration — open the assistant editor and click the **⋮ (three-dot menu)** next to the Save button. Select **Duplicate**.

A copy of the assistant is created and added to the list. Open it to rename and adjust the configuration as needed.

## Archiving an Assistant

Archiving an assistant removes it from the active Assistants list and from the chat interface. Archived assistants are not permanently deleted — they can be viewed by enabling the **Show archived** toggle on the Custom Assistants page.

To archive an assistant, open the assistant editor and click the **⋮ (three-dot menu)** next to the Save button. Select **Archive**.

<Frame>
  <img src="/images/graphium/assistant/duplicate-archive-assistant.png" alt="Three-dot menu showing Duplicate and Archive options" />
</Frame>

The assistant is moved to the archived state immediately and will no longer appear in the active list, the sidebar, the workspace **Assistants** tab, or the chat interface.

Conversations people had with the assistant are kept. They're labeled **Inactive** in the **CHATS** list and can still be read, but not continued. See [Chats with an Archived Assistant](/graphium/ai-assistants/the-ai-assistant-welcome-screen#chats-with-an-archived-assistant).

---

## Returning to the Chat

From the assistant editor, click the **← back arrow** in the top-left to return to the Assistants list.

To go back to the vault chat from the Assistants list, click **Home** in the vault sidebar. This returns you to the vault home page with the chat interface.

## Troubleshooting

| Issue | Likely Cause | What to Do |
|-------|--------------|------------|
| Save button does not work | Name or system prompt is missing | Both fields are required — check that both are filled in before saving |
| Tools tab is not available | The assistant has not been saved yet | Save the assistant once, then the Tools tab becomes editable |
| Assistant is not visible in the chat interface after saving | The assistant has been saved as a draft but not yet published | Click **Publish** in the top-right header of the assistant editor |
| Changes made to an existing assistant are not visible to users | The updated version is saved as a draft but not published | Open the assistant editor and click **Publish** |
| The ⚙ (Manage assistants) button is missing from the sidebar | The sidebar button is for vault Admins only | Builders can use **Manage assistants** in the assistant selector. Contributors and Viewers should ask a vault Admin for Builder access |
| + New Assistant button is missing | Your vault role is Contributor or Viewer | Contact your vault Admin to request Builder or Admin access |
| Archived assistant still appears in chat selector | The page may be cached | Refresh the page — archived assistants are removed from the active list immediately on the server |
| Test Chat is not responding | The system prompt may be too vague, or the AI model may be temporarily unavailable | Try sending a more specific message, or check your internet connection and retry |
| An assistant is not visible to some vault members | Access is restricted to specific roles | Open the assistant editor, go to the General tab, and review the **Who Can Access** setting |
| Allow column changes toggle is missing on a table | The table is set to Off or Read only | Set the table's access level to Read & Write to reveal the toggle — see [Configuring Chat Context](/graphium/ai-assistants/configuring-chat-context) |
